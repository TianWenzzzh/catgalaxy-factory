被测页面：`http://127.0.0.1:8010/`（五步控制台）

> 因此 `take_screenshot` 与指针类 `click` 全部返回 `NATIVE_BROWSER_VIEWPORT_UNAVAILABLE`，**无法产出截图**。
> 改用两条等价手段取证：① `take_snapshot` 取可访问性树（结构证据）；② `evaluate_script` 触发真实 DOM 事件
> （`element.click()`、`input.files` 由 CDP 注入、真实 `fetch`），并直接读取页面状态与 canvas 像素。
> 所有断言均来自浏览器内真实执行结果，非 Python 侧模拟。
