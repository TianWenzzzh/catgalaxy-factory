3校验报告（F2）

还没有校验结果。上传名册与照片后点「运行校验」。

把有错误/警告的行直接摊开改，不用再「下载 CSV → 改 → 重新上传」绕一圈。 改动写回项目的 roster.csv 与 data/猫咪名册.csv（带 BOM，Excel 不乱码）。 删行有两个入口：问题行右侧的「✕ 删这行」，和上面「－ 删一行」里按编号挑 （名册干净时没有前者）。两者都只删名册里那一行，照片不动，会变成「未使用照片」提示。

编号留空就是留空——工具不替你编编号，校验会报「编号为空」， 由你决定用哪个号（弃用编号不复用是数据红线）。

表头（第 1 行）不能删。删掉的猫会从星图里消失，但它的照片仍留在工作区， 报告里会以「未使用照片」提示——要不要清掉由你决定，工具不替你删文件。

F8星位标定 · 让星星落在真实地点

算法只保证「同区聚拢、区间分开」。要让星星对上猫真实出没的地理位置， 需在校园底图上人工点位：先在预览里开启标定模式，拖动星星到正确位置，再保存回项目。 整片偏了不用逐星拖：Shift+拖拽一颗星 = 它所在出没分区全体一起平移。

F9归并工作台 · 疑似同一只猫

两路召回候选组：共用同一张代表照片（最可能是重复建档）、 同毛色 + 同出没区域且特征描述相似。左右并排看图后判定，理由会写进操作日志， 并自动出现在《归并决策摘要》第六节——数据红线要求每条取舍都留痕。

组内卡片已按视觉相似度（感知哈希，同一张图重压过也认得出）排序， 并标出每只猫在组里最像谁——从左边第一对看起就行，不必两两都比一遍。 这个分只决定「先看谁」，不掺进可疑度：同色猫扎堆本来就长得像， 像不像跟是不是重复建档是两件事，判定始终由人下。

F11星图主题 · 配色 / 字体 / 署名 / 校徽

产物是要拷给别人、双击就能打开的，所以不引用任何外部资源：字体只用系统里 本来就有的（不打包 webfont），校徽在相对版里写成 assets/logo.png、内嵌版里转成 base64。预设全是深色底——星点是画在 canvas 上的亮色小圆点，换浅色底就是一片看不见星星的白。

署名是追加，不是替换：数据源、生成日期、标定方式这三样是留痕要求， 想加自己的落款可以，想把出处抹掉不行。署名会被 HTML 转义，写标签也不会变成代码。

改任一颜色即为「自定义」，会在切换预设时清空。值只收 #RRGGBB， 其余一律丢弃并提示——这些值会被拼进产物的 <style> 里。
